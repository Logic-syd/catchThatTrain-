# 虹桥10号线终点与换车任务 V1

日期：2026-10-17。适用于四个已开放人物、普通与极限模式的上海虹桥地铁流程。

当前主线此前没有航中路／龙溪路分支状态；可访问历史中也未找到对应实现。本次补上实际下车与同线换车，不把它塞进30%通用随机事件。

## 玩家流程

选择10号线的同侧方向后，上车看本班终点：虹桥火车站或航中路。虹桥班次继续坐；航中路班次在龙溪路实际点击下车，进入站台，认清终点并选择下一班虹桥火车站列车。站台展示两趟车及各自后果。继续坐、关门未下车或重新上航中路班次会折返龙溪路，玩家仍需下车换车。

标题与说明保持简短，中英文同步；保留线路、站名、终点、费用与关门时间，不展开属性公式。地图和车内场景中的“要去的地方”是玩家目标；“本班终点”是当前列车实际终点，两者有意分开。

## 范围与稳定标识

| 路线 | 行为 |
| --- | --- |
| `sh-n-10` 南京东路→10号线 | 上车后显示终点，龙溪路处理分岔 |
| `sh-j-10` 交通大学→10号线 | 同上；龙溪路在上海动物园前 |
| `sh-p-x` 人民广场→8→10号线 | 老西门完成原跨线换乘后，才显示10号线终点；龙溪路再次换车 |
| `sh-n-x` 2→10，虹桥2号航站楼换乘 | 已在分岔之后，不触发航中路换车 |
| 2号线及其他车站路线 | 无本任务 |

`metroBranch` 独立记录当前终点、站台访问号、已付款状态和误乘次数；`metroTransferred` 仍只表示原计划的跨线换乘。`ROUTE` 时用本局已锁定的 `metroIncidentVariant` 规划终点（小于0.5为航中路），不新增随机源消费；不受30%通用事件是否发生影响。渲染、语言切换、地图和停站不会重新抽签。

`metro-platform` 是实际站台阶段；`ALIGHT` 进入，`BOARD_METRO {terminal,visit}` 登车，`terminal` 只接受 `hongqiao/hangzhong`。访问号和阶段共同拒绝过期回调与重复登车；下一次回到站台必须使用新的访问号。

## 成本、收益与结算

| 行为／日志 ID | 固定游戏秒 | 等待份额 | 结果与消费者 |
| --- | ---: | ---: | --- |
| 龙溪路正确下车／`metro-branch-platform` | 0 | 0 | 打开换车站台；学生另沿用既有靠门规则 |
| 航中路班次换上虹桥班次／`metro-branch-wait` | 30 | 30 | 终点变为虹桥，继续原路线；等待按原资源上限恢复 |
| 坐对班次却下车，再等虹桥班次／`metro-branch-extra-wait` | 30 | 30 | 可避免的额外换车，计导航操作损失 |
| 坐过龙溪路／站台再次上错／`metro-branch-missed` | 65 | 0 | 折返到龙溪路到站状态，误乘计一次，仍需实际下车换车 |

30与65由 `METRO_BRANCH` 常量统一供按钮、引擎、预测与模拟读取，是本次新增游戏费用，不是现实地铁时刻。读题、关门、登车点击和折返展示期间，原有计时照常推进；没有另一套时间或自动补时。

学生提前靠门可免下车12秒，未靠门仍收既有12秒一次。误乘折返会沿用原恢复流程清除靠门状态，因此恢复后下车可能有这笔费用；它与65秒折返、30秒等车分别归因。其余人物不新增学生靠门费用。

换车保持 `route`、`metroProgress`、`metroDuration`，不重新收整段地铁路费、不把剩余路程清零。等待由同一 `waitSeconds` 计划结算，家长尿意继续读取全部实际扣时一次；折返不赠送站立恢复。资源上限、库存、移动倍率与本局预算不改。

已显示航中路终点后，预测加入尚未支付的30秒换车等待，支付后立即移除；路线选择前显示可能额外等候30秒，不提前泄露本班终点。必要换车等待归环境，误乘归导航；组合“坐反方向＋错过分岔”的错误次数累加，学生自身计数不重复。站台逗留、固定等候和误乘截止各保留真实终止位置。

游客若睡到龙溪路仍未醒，先触发醒来操作，不能借睡眠跳过必要换车。若早于所设闹钟，文案明确是龙溪路换车提醒；已到闹钟站点沿用原提醒。原补觉收益、醒来操作、再次睡过的费用不变。

## 验证与后续修改

新增或修改终点、换车站、费用和输入时，继续遵循[任务成本收益](./任务成本与收益规则_V1.md)、[等待状态与操作](./等待状态与操作规则_V1.md)、[预算与预测](./预算实际耗时与预测规则_V1.md)及[双语规则](./中英双语显示规则_V1.md)。同时修改模拟的到站判断和实际登车输入，不能让旧脚本在龙溪路反复误乘后称为新难度数据。

两套模拟脚本已升级到v5输入模型。专项288局覆盖四人物、双模式、三条相关线路、两个终点、正常与两种误乘恢复，均到达火车站并产生终局，资源有效。原路线费用和正式预算在配对样本中一致，正确虹桥班次分支费0、航中路正常换车30、误乘再恢复分支费95；学生既有未靠门费单列。

288局中145成功、143在站内失败，样本刻意包含慢路线和误操作，**不是人物成功率校准**。交通大学／人民广场起点使用显式路线覆盖状态，并按正式 `openingBudget` 重算该起点预算；不能称为当前默认起点的真人流程。另有两套生产脚本各144局的流程与资源回归；本轮不调参，也不沿用旧输入模型的胜率结论。
