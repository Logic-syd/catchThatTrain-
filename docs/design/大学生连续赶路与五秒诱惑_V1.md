# 大学生连续赶路与五秒诱惑 V1

2026-10-17 修订，适用于大学生六站。本规则替代虹桥模板中“仅虹桥自动续走”和其他五站强制拒绝诱惑的旧行为；其他人物机制不在本次迁移范围。正式预算、任务定额费用和资源上限不变。

## 操作合同

- 首次点击前进或按住冲刺启动；必经任务完成后自动恢复普通步行，不再每段重新启动，也不自动恢复冲刺。
- 手动暂停、打开地图／票据和窗口失焦会清除续走意图；关闭窗口后需玩家主动开始，不能偷偷恢复。
- 小猫、围观、扶奶奶、奶茶四项诱惑改为路边提示。提示出现后持续 **5 个真实秒**，不点就消失，继续走路，不需要点击拒绝。
- 提示期限由引擎累计 `elapsed` 管理，使用绝对截止值；不是 HUD 的四倍游戏秒，不另外开 UI 计时器。跨路段、切换中英文、重新渲染都不能重置期限。
- 必经任务与碰撞提示优先显示，诱惑暂时隐藏但期限继续推进；任务结束时若仍在期限内才显示剩余时间，过期不补弹。多个机会依次显示，每个机会只创建一次。
- 只有点击尚未过期的提示才停下，随后完成原长按操作。接受后不再受提示的五秒期限限制，必须完成实际活动。
- 接受跨路段提示不跳过当前道路、空间入口或必经任务。完成活动后从原位置继续普通步行。
- 接受输入必须携带原机会的 id 与 revision；旧按钮、重复回调和过期点击不得收费或发奖。

## 成本、收益与后续消费者

| 活动 | 完成时原定额费用（游戏秒） | 活动类型 | 剧情收益 |
| --- | ---: | --- | --- |
| 摸小猫 | 30 | 等待 | 幸福感 +20 |
| 围观 | 40 | 等待 | 幸福感 +20 |
| 扶奶奶 | 35 | 步行 | 道德 +20 |
| 买奶茶 | 25 | 等待 | 幸福感 +20 |

忽略提示的定额费用为零、奖励为零、参与次数不增加；路上经过的时间仍按统一时钟自然流逝。主动参与时，读题和长按消耗的真实时间照常推进，活动完成再结算既有定额费用一次，不能把两者混为同一项。等待／步行的恢复或消耗沿用统一规则及自身资源上限。幸福感和道德只供剧情与结算展示，不能变成赶车速度、体力、专注或预算加成；准备页奶茶的实际收益仍独立遵循准备规则。

预测使用同一剩余道路和必经任务，并单独加入已经接受的活动；未接受的诱惑不是必做成本。活动费用、参与次数和剧情奖励的消费者为结算与日志，须一次性对应。新增诱惑也必须满足以上合同，不得重新引入“拒绝后再启动”。

## 奶茶图标与文案

准备页、路边提示及活动页统一使用本地 SVG。参考霸王茶姬、茶颜悦色、卡旺卡的视觉气质，绘制红色人物印章、米色人物折扇、橙色杯标三种原创图形。上海／北京使用印章，杭州／武汉使用折扇，广州／郑州使用杯标。图形为装饰，短文案和操作保留中英文切换。

- 全套测试 47 文件、658 项通过；最后调整“必经任务时隐藏提示”后，组件与引擎定向 31 项再次通过。生产构建通过。
