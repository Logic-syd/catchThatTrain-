# 难度校准规则 V1

后续修订：用户已明确大学生85%–90%、打工人70%、游客60%、带娃家长40%、未来家庭20%，中间三档允许上下浮动3–5个百分点。当前政策和新验证以[难度区间与首关体验 V3](./难度区间与首关体验_V3.md)为准；本页预算、目标解读与结果保留为此前版本的证据，四人物上一轮完整矩阵仍见[历史V2](./难度阶梯校准_V2.md)。

本轮目标来自用户要求：大学生要有最后赶上的紧张感，普通和极限模式都接近85%成功率；游客成败应明显受操作影响；家长需要可玩的照顾余量，为未来家庭模式保留更高难度。以下是固定策略模拟的设计与验收规则，不把它称为已经测得的真人首玩概率。

## 1. 目标与不可采用的做法

- 大学生：合理新手基准两种模式均约85%，容许样本波动。同时报告成功检票余量的中位数、低于45秒的局数，以及熟练／频繁失误对照，不能只给总体比例。紧张感仍需真人试玩确认。
- 游客：使用同局种子、相同准备及路线，比较熟练、合理新手、频繁失误。正确处理应有可靠通关空间；漏闹钟、判断错误、碰撞和迟缓操作要通过真实费用影响结果。不得把次快地铁路由绑定“差操作”，也不能用隐藏随机必败代替操作差异。
- 家长：普通模式合理操作应有较高通关空间，极限仍可挑战，不能落在原来约3%的固定策略成功率。保留孩子状态管理、较低冲刺加速与较高体力消耗、尿急禁冲刺。5星家庭尚未实现，本轮不新增该模式。
- 所有预算在创建本局时确定；不按输赢、剩余时间或玩家表现动态赠送时间，不回避失败种子，不改变时间倍率、资源上限、等待一次性结算来凑胜率。

## 2. 本轮参数及完整消费者

| 项目 | 旧参数 | 现行参数 | 实际作用与边界 |
| --- | --- | --- | --- |
| 学生准备：奶茶／检查证件／早餐 | 120／30／60秒，总210 | 45／10／25秒，总80 | 收费、静态与动态卡片、日志、报告、称号和成就读取同源常量；能力与容量收益保留，不把节省费用虚记为资源收益 |
| 学生开局操作余量／极限削减 | 240／120秒 | 70／0秒 | 收紧不准备时的大量余裕，同时避免全准备成本过高；两种模式使用同一开局预算政策，极限仍有原有额外事件 |
| 游客开局操作余量／极限削减 | 480／360秒 | 100／30秒 | 移除游客上海2130秒旧下限，减少无失误与大量失误都能轻松过关的预算；线路价格公式不变 |

打工人预算和资源参数保留。学生总准备费用现在低于原来的120秒称号门槛，因此“准备齐仍赶上”等组合条件改读真实总费用80；奶茶、早餐败因阈值读取各自真实费用，独立的成功余量窗口仍单独定义。

表中的预算是基础值。六站检查后另有开局固定的任务余量修正：学生上海+30、广州−30；游客上海+30；家长上海+30、广州+60。它们表达不同站点的固定任务负担，不读取本局随机种子、已遇事件或玩家表现。不能只看总体达标而容忍某站熟练操作仍大量必败。

极限 `old-ticket` 原来随机宣布“玩家点错日期”，正确处理也强制收费60秒，不能归因于玩家本局操作。现在改为手机中混有旧票，`current-ticket` 核对并打开今天车票花8秒，`stale-ticket` 拿旧票尝试后处理花60秒，非学生未处理超时额外扣60秒一次且仍须完成选择，之后正常办理费用另计；学生沿用现有专注超时规则，只标记逾时、不另扣这60秒；原稳定任务ID保留。随机只决定是否遇到核对题，额外损失来自实际误选或超时。卡片明确费用，仍需真实读题／点击，不凭刷新或重试重复结算。该题使用普通选择操作，旧票没有真实购票或付款行为。

游客HUD显示实际普通移动倍率和真实恢复档位，硬拖轮子的减速、每真实移动秒额外耗能1及储备消费顺序保留。家长提前厕所现在更有机会避免长站内再次付费如厕；未准备、绕路、长时间停留仍会按同一时钟累积尿意，不保证一次准备消除所有后续风险。

校准时同时发现路线收益目标受人物任务插入影响：上海长廊／广州通路的 `travelScale` 曾缩放“下一段”，家长任务插入后会误缩放孩子任务前的路段。现用稳定 `travelBeat` 明确指向 `security-queue`／`gz-crossing`，与实际旅程和预测共用修改后的段长。路线密度、跳过换层和固定费用保留；四人物两站两路线均有回归。

## 3. 操作基准与复现

脚本：[simulate-skill-balance.ts](../../scripts/simulate-skill-balance.ts)。默认固定 balanced 准备及公开计价最快地铁路线，只改变输入品质。普通与极限使用同档参数；模式内三档共享本局种子与按事件键确定的操作随机值，避免慢操作多遇一次事件就打乱整局误操作样本。极限会改变游戏随机数消费，所以跨模式不声称所有遭遇相同。

| 操作参数 | 熟练 | 合理新手 | 频繁失误 |
| --- | ---: | ---: | ---: |
| 读题基准真实秒（固定种子扰动±20%） | 1.2 | 2.2 | 3.6 |
| 每次点击真实秒 | 0.18 | 0.28 | 0.45 |
| 到站判断真实秒 | 0.6 | 1.0 | 1.8 |
| 可见判断误选概率 | 0% | 8% | 22% |
| 障碍反应真实秒 | 0.25 | 0.65 | 1.2 |
| 漏看障碍概率 | 0% | 10% | 28% |
| 游客闹钟反应真实秒及扰动 | 0.8±0.4 | 1.7±1.0 | 2.9±1.6 |

按住时长使用游戏 `eventHoldSeconds`；连点、滑动、找证件、队列观察都花实际操作时间。身份证按可见提示搜索，不直接读取隐藏正确夹层；看不出队列处理速度时依据可见人数选择。错误下车、错号、超时和撞上障碍均走引擎原动作与处罚，不直接注入 `PENALTY`。

三档都使用70%精力开始／30%停止的节奏冲刺；学生负荷达到4秒后缓和至1秒，家长距离差达到4后等待回到2，遵守尿急限制。本基准不主动使用家长一次性同步冲刺。balanced 学生不买奶茶、检查证件、吃早餐；游客咖啡并轻装、提前2站叫醒；家长提前厕所并带零食。lean／prepared 作为敏感性对照，不假定所有真人都选同一套准备。

```bash
node_modules/.bin/vite-node scripts/simulate-skill-balance.ts --samples=20 --characters=student,tourist,mom > /tmp/balance-calibration.jsonl
node_modules/.bin/vite-node scripts/simulate-skill-balance.ts --samples=40 --offset=1000 --characters=student,tourist,mom > /tmp/balance-holdout.jsonl
```

输出每局实际预算、准备、路线、输入错误、超时、碰撞、闹钟反应、检票／发车余量。失败与准备阶段提前结束同样计入分母；卡死或资源异常直接报错。当前创建入口固定默认起点，未覆盖未来全部出发点。原来的三方案等权、正确答案与完美避障复测是不同口径，保留在[上一轮报告](./难度成功率复测_2026-10-10.md)，不能直接当成本轮新手基准的对照。

当前输入模型为v2：旧票已变成可见判断题，纳入同档误选率。旧版本v1基线及中间校准输出保留，不把其旧强制费用题的结果说成完全相同的任务／输入对照。sample 0–19用于初调，100–139用于发现站点问题；最终验证另用未参与调参的1000–1039。

## 4. 后续改任务时必须复验

1. 沿用任务成本收益、等待和资源规则，说明操作、等待与步行时间，以及明确的后续消费者。
2. 用未改预算的正式创建入口，保留准备、读题和输入成本；同时检查成功率与成功余量，不能靠零读题、完美回答或给失败局补时来通过。
3. 涉及游客时比较同种子操作档，检查操作变好确实能改变输赢；涉及家长时复查提前厕所、库存、尿急禁冲及长站的组合。
4. 使用额外未参与校准的种子检验，记录各站与两模式；不得只报告更好看的种子或准备方案。脚本假设变更后须重新生成前后基线。
5. 修改费用要同步卡片、日志、报告、成就和称号，修改路线效果使用稳定目标段，避免新增人物事件让收益错位。


## 5. 最终独立验证结果

最终参数冻结后使用 sample 1000–1039，共40个未参与校准的种子 × 六站 × 三人物 × 两模式 × 三操作档 = **4,320局**。每个表格单元格240局，全部采用 balanced 准备及最快公开路线；没有替换失败种子或补时间。

大学生两模式约88%，接近85%目标，并非程序指定85%的胜负。合理新手成功局检票余量标准中位数为普通72.81、极限72.34游戏秒；普通50/210、极限52/211成功局低于或等于45秒，约24%。这比早期动辄剩几分钟的通关更紧，但不能称每局都压哨；熟练档仍全部通关且余量标准中位数为普通106.12、极限107.61游戏秒，极限也没有在本样本中形成更小的总体成功余量。真人主观紧张感仍需试玩，不由模拟百分比保证。

游客同模式、同种子、同准备／地铁路由的480组操作配对中，没有较差操作档反胜。普通熟练→新手有37组由胜变负，新手→频繁失误有187组；极限分别71、162组。频繁失误档每模式145/240次闹钟未及时处理，每次引擎实际扣80秒；新手还包含真实坐过站、找证件超时和避障碰撞。上海熟练两种模式均40/40通过，旧票正确检查8秒，误选60秒均有实际轨迹，不再存在原诊断样本中的无误操作强制旧票失败。此结论来自本基准的可观察输入差异，不代表所有可能操作策略或所有路线。

家长普通新手88.75%、极限67.08%，恢复了照顾与补救空间；六站两模式熟练全部40/40通过。广州新手为普通34/40、极限25/40，原“熟练仍大量截止”的问题未再现。提前厕所后1437局没有再次如厕，3局因停留较久再次付75秒如厕且仍成功；说明照顾需求保留，而不是直接关闭尿意。家长普通模式当前较宽松，这是本轮为可玩性与后续家庭模式留空间的选择，不能把它解释成4星必然比所有低星通关率低。
