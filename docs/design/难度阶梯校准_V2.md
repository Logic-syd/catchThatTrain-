# 难度阶梯校准 V2

本页是上一轮参数与14,400局结果的历史记录。用户随后明确学生85%–90%、中间三档允许上下浮动3–5个百分点；现行目标、学生余量及首关操作反馈见[难度区间与首关体验 V3](./难度区间与首关体验_V3.md)。下文旧结果不改写为新参数的证据。

修订日期：2026-10-11。用户明确五档成功率目标后，本页替代[难度校准规则 V1](./难度校准规则_V1.md)中“家长普通较宽松”的目标与旧预算政策。V1及原始设计稿保留为历史记录；任务成本、等待结算和资源边界规则继续适用。

## 1. 五档目标

| 人物 | 星级 | 合理新手成功率目标 | 状态 |
| --- | ---: | ---: | --- |
| 大学生 | 1 | 85% | 已开放 |
| 打工人 | 2 | 70% | 已开放 |
| 游客 | 3 | 60% | 已开放 |
| 带娃家长 | 4 | 40% | 已开放 |
| 家庭 | 5 | 20% | 后续实现，尚未复测 |

沿用此前普通和极限均接近目标的校准口径，按六站平均的合理新手操作衡量。目标不是在引擎中抽签决定胜负，也不是已经测得的真人通关概率。不同准备、路线、熟练度和车站可以产生不同结果，必须同时公开这些差异。学生的紧张感还需看检票余量与试玩，游客继续要求同局操作改善能提高成功机会。

目标的代码来源为 `src/difficulty.ts` 的 `DIFFICULTY_TARGETS`。家庭20%只是一项未来验收目标，不能作为已上线角色的模拟结果；实现后须通过正式入口、真实预算和完整准备／操作成本复测。

## 2. 固定预算与完整消费者

只调整创建本局时的操作余量和固定站点修正。最快路线价格、移动时钟、30秒预算取整和180秒检票偏移继续共用 `timeModel.ts`；没有第二套路线公式。普通和极限不再使用原打工人360秒的整体削减，极限仍保留现有的核对旧票等事件差异。

完整链路为 `difficultyPolicy` → `openingBudget` → 正式创建入口的 `initial/remaining` → 开场与HUD倒计时、地铁/站内实际截止、预测和结算账本。预算本身不恢复精力、不消费库存、不改变尿意或掉队规则，任务费用仍只结算一次。

固定站点修正用于已有旅程长度与人物任务的实际负担，在开局、输入前确定；不读取随机种子、遭遇、剩余时间、成功与否或操作档。删除旧上海打工人预算下限，使其与其他站共用同一公式。资源和准备的能力、费用及收益链路沿用V1最后实现，不通过提高上限或停用照顾需求调胜率。

## 3. 输入模型与验证要求

采用[操作模拟脚本](../../scripts/simulate-skill-balance.ts)的v3输入模型。保留v2的读题、判断、避障、查找和闹钟输入，并加入人物新机制的可见选择；不能把旧旅程的v2结果直接当作本版基线。每档都使用合法节奏冲刺与最快公开地铁路线，保留实际按住、点击、等待和准备费用。失败计入分母，卡死或资源异常直接报错。

| 输入参数 | 熟练 | 合理新手 | 频繁失误 |
| --- | ---: | ---: | ---: |
| 基础读题真实秒 | 1.2 | 2.2 | 3.6 |
| 判断失误概率 | 0 | 8% | 22% |
| 避障失误概率 | 0 | 10% | 28% |
| 学生每次停下接受诱惑的概率 | 4% | 28% | 65% |
| 游客未知路口先看牌／问路的概率 | 100% | 80% | 40% |
| 家长发作时选择长时间训话的概率 | 0 | 8% | 35% |

游客确认信息时，25%问工作人员、75%看路标；不确认时在两条可见连廊间猜选，确认后仍按本档判断失误概率可能走错。模拟从当前卡片文字读取方向，不读取地图隐藏答案。打工人的公司任务同样按可见选项判断，失误时可能立刻做事或暂不回应，后续追问实际变长。读题时长按同局固定输入噪声浮动；其他完整参数随原始输出元数据保存。这些概率是公开的操作模型假设，尚未由真人试玩测量。

balanced 准备：学生跳过奶茶、检查证件、吃早餐；打工人不带土特产、吃饭、回复老板；游客咖啡、轻装并提前两站叫醒；家长提前厕所、带零食。家长基准不主动使用一次性牵手同步冲刺。这是统一的方案对照，不代表玩家真实选择的分布。

初步校准种子为 sample 2000–2039。首轮冻结参数在 sample 6000–6099 上复测后，学生88.7%／87.8%、打工人72.2%／73.5%、游客61.5%／60.5%、家长44.7%／43.3%（普通／极限），学生与家长偏高，随后小幅收紧固定站点余量。这批结果因此转作调参诊断，保留原输出，不宣称是最终参数的独立证据。最终冻结参数另用 sample 10000–10099，不能在看到验证结果后改用更好看的种子。输出记录实际难度政策与五档目标，方便区分历史批次；同模式不同操作档使用同种子和相同准备／路线，跨模式不保证随机事件完全相同。

后续调整人物或任务时必须：

1. 复查四个已开放人物在普通／极限的目标及排序，不能只报告单一人物或总体平均。
2. 报告各站成功率、检票余量和熟练／频繁失误对照，诊断无误操作仍失败的具体原因。
3. 保留统一时间、资源上限、尿急禁冲刺、等待定额替代和任务收益的回归；不注入罚时、补时、隐藏必败或免费恢复。
4. 使用未参与调参的额外种子验证；输入模型改变时重做基线，目标与样本比例有偏差时直接报告。
5. 修改费用同时检查卡片、引擎、日志、报告、成就与称号；修改路线效果使用稳定目标路段。

复现最终矩阵：

```bash
node_modules/.bin/vite-node scripts/simulate-skill-balance.ts --samples=100 --offset=10000 --characters=student,worker,tourist,mom > /tmp/ladder-holdout.jsonl
```

## 5. 最终独立验证结果

最终样本为10000–10099，四人物×六站×两模式×三输入档，共14,400局；每个人物每模式每输入档600局。全部正常结束，资源边界检查通过，共20,660,624次状态转换。没有使用额外补时、隐藏必败或失败重抽。

| 人物 | 目标 | 普通合理新手 | 极限合理新手 | 普通／极限成功检票余量中位数 |
| --- | ---: | ---: | ---: | ---: |
| 大学生 | 85% | 82.2%（493/600） | 81.3%（488/600） | 67.2／67.7游戏秒 |
| 打工人 | 70% | 70.2%（421/600） | 70.0%（420/600） | 49.5／50.4游戏秒 |
| 游客 | 60% | 58.8%（353/600） | 58.5%（351/600） | 57.8／60.4游戏秒 |
| 带娃家长 | 40% | 43.5%（261/600） | 44.3%（266/600） | 21.6／21.6游戏秒 |

学生仍比85%目标低2.8／3.7个百分点，家长比40%高3.5／4.3个百分点；两模式均保留预期难度排序。本轮把目标理解为近似校准，报告偏差，不把实际结果写成精确85%／70%／60%／40%。30秒预算取整也限制小调整的粒度。家庭20%未实现、未模拟。

按种子组对六站共同重采样10,000次，合理新手成功率的95%区间（描述模型抽样误差，不是真人概率区间）：

- 大学生：普通78.8%–85.3%，极限78.2%–84.3%。
- 打工人：普通66.7%–73.7%，极限66.5%–73.7%。
- 游客：普通55.0%–62.5%，极限54.5%–62.3%。
- 带娃家长：普通39.2%–47.7%，极限40.0%–48.7%。

同模式、同种子与相同准备／地铁路线下的操作对照显示明显差异，游客尤其如此；变化来自寻路选择、信息确认、判断、避障、读题和闹钟反应的共同改善，不是只改变一个“问路概率”的因果实验。偶然猜对可省去确认时间，不承诺每一局逐项提高输入都严格单调。

游客同局从频繁失误改善到合理新手，普通335局、极限332局由失败转成功，各有1局反向变化；改善到熟练则另有247／249局由失败转成功，没有反向变化。本例反向变化来自具体选择路径，不能为了凑严格单调而强制改判结果。

家长熟练普通的唯一失败是上海sample10036（seed999312542）：没有判断错误、碰撞或坐过站，止于刷证前，模型估计仍差1.2游戏秒；熟练输入并不代表全局最短路线。保持相同种子、预算、准备和其他输入，只把长廊选择改为已公开的商店旁近路，复现成功，检票余量16.6秒。此对照没有加时间或减孩子负担，说明该局不是隐藏必败。额外复现不并入14,400局基准；文件为`/workspace/scratch/personality-parent-shortcut-repro.jsonl`。基准与更短路尝试均按真实避障规则进行。
