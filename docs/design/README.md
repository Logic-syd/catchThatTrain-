## 当前规则与版本优先级

2026-10-15 确认：本周提交 `0e5d0bccb01a825b93943cee15331d972a3a044f` 是本次整合的实现基线；上周 PR #9 的 `40fc58dae1959dacbf7f896b8a2588538bf97749` 用于保留历史，冲突以本周规则为准。不能根据 PR 编号、分支名称或检查运行时间判断功能的新旧。

上周的设计和 19 份 JSON 报告已列入[历史分支资料索引](./历史分支资料_2026-10-09.md)，均不替代现行规则。分支、CI 和合并范围见[分支整合说明](../handoff/分支整合说明_2026-10-15.md)。
