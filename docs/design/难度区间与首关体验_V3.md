# 难度区间与首关体验 V3

修订日期：2026-10-11。用户明确“学生可以在85–90之间，因为是第一关，给大家一点愉悦感，重点是让大家有我很厉害的操作感。中间几个成功率可以上下浮动3–5”。本页替代[难度阶梯校准 V2](./难度阶梯校准_V2.md)中的现行目标与学生预算；V1/V2及原始设计稿保留为历史。任务成本、资源边界、等待、人物事件和统一时间规则继续适用。

## 1. 目标与验收口径

| 人物 | 合理新手六站平均目标 | 优先区间 | 最大允许区间 |
| --- | ---: | ---: | ---: |
| 大学生 | 85%–90% | 85%–90% | 85%–90% |
| 打工人 | 70% | 67%–73% | 65%–75% |
| 游客 | 60% | 57%–63% | 55%–65% |
| 带娃家长 | 40% | 37%–43% | 35%–45% |
| 家庭 | 后续20% | 未设定 | 未开放、未验证 |

普通与极限分别验收，不合并成一个百分比。沿用既定的合理新手、六站等权口径；不是要求每个车站或所有操作档都达到同一比例。按站结果、操作差异和成功余量必须同时公开。中间三档优先靠近±3个百分点，最多允许±5个百分点；改人物或任务后仍检查四档排序。

`src/difficulty.ts` 的 `DIFFICULTY_TARGETS` 将学生报告中心设为87.5%，`DIFFICULTY_TARGET_RANGES` 提供四个已开放人物的允许区间，操作模拟输出这两项元数据。这些是校准指标，不是引擎抽签决定胜负的参数。未来家庭实现后另做正式预算与完整流程验证。

## 2. 第一关的操作成果

学生首关以合理操作较容易成功、实际动作有可见回报为目标。保留摸猫、围观、扶奶奶、买茶颜悦色四种诱惑；幸福感／道德只进入剧情，不提高赶车能力。检查身份证、早餐、选路、观察队伍、及时下车、避障和节奏冲刺仍有真实作用。成本与消费者见[人物难点与事件规则 V2](./人物难点与事件规则_V2.md)及[准备收益规则](./准备收益与任务资源规则_V1.md)。

站内新增“本局操作表现”：

| 反馈 | 来源与边界 | 消费者 |
| --- | --- | --- |
| 避开路障 N 次 | 本局 `student.runner.dodges`；实际通过路障才累计，碰撞不记为避障，新局从0开始 | `Station.tsx` 实时展示；既有详细复盘继续读取同一记录 |
| 冲刺追回约 N 秒 | 本局 `student.sprintSaved` 向下取整；是实际有效冲刺相对于普通速度的估算游戏秒，不是赠送倒计时 | `Station.tsx` 实时展示；既有结算估算口径继续保留 |

展示不改状态，不额外加精力、时间、积分、连击奖励或成就。事件、碰撞、停步解除冲刺等统一规则继续适用。不会为了制造惊险临时压缩时间，也不会在落后时返时。合理新手保留一定紧张余量，熟练操作可以更从容；不要求每场成功都卡在最后几秒。界面与模型能验证这些反馈的真实性，愉悦感和“我很厉害”的感受仍需真人试玩观察。

## 4. 独立种子复测

学生用未参与调参的 sample 14000–14199：六站×两模式×三输入档×200，共7,200局，4,826成功／2,374失败，8,607,466次状态转换。全部结束，资源边界检查通过；失败保留在分母，无补时、重抽或强制胜负。

输入模型仍为v3，沿用V2的合理新手读题2.2真实秒、判断失误8%、避障失误10%、每次接受诱惑28%等假设；未通过更换输入模型提高胜率。学生准备为跳过奶茶、检查证件、吃早餐，选择最快公开地铁路线并合法分段冲刺，保留实际准备、阅读、点击、按住和等待成本。操作档是明确的模拟假设，不代表已测得的真人首玩概率。

| 学生操作档 | 普通 | 极限 |
| --- | ---: | ---: |
| 熟练 | 100.0%（1200/1200） | 100.0%（1200/1200） |
| 合理新手 | **86.9%（1043/1200）** | **87.5%（1050/1200）** |
| 频繁失误 | 13.6%（163/1200） | 14.2%（170/1200） |

同模式同种子、相同准备和地铁路线，将频繁失误改善为合理新手，两模式各880局从失败转成功；将合理新手改善为熟练，普通157局、极限150局转成功，本批均无反向变化。差异来自读题、判断、避障、下车、诱惑和操作节奏的共同改善，不是只改冲刺或一个选项的因果实验，也不是对所有未来种子的单调性保证。

学生合理新手成功检票余量普通中位83.1游戏秒、极限82.1游戏秒；普通229/1043局、极限239/1050局在45游戏秒以内，合计22.4%。各局均使用实际时间规则。合理新手平均接受1.09次诱惑、固定停留35.5游戏秒；这两项以全部2,400局为分母，包含提前失败的局。

按200个种子组对六站共同重采样10,000次，合理新手成功率95%区间为普通84.9%–88.8%、极限85.6%–89.3%。它们描述模型的抽样误差，点估计达标不等于真实总体或真人通关率已经精确确定。

```bash
node_modules/.bin/vite-node scripts/simulate-skill-balance.ts --samples=200 --offset=14000 --characters=student > /tmp/student-joy-holdout.jsonl
```

原始结果为 `/workspace/scratch/student-joy-holdout-v3.jsonl`；聚合脚本、元数据／配对／源码及原始文件SHA256分别为 `aggregate-student-joy-v3.py`、`student-joy-summary-v3.json`、`student-joy-source-manifest.json`。本轮种子现已属于验证历史，后续调参后须另用未参与调参的种子，不挑更好看的样本。

后续修改准备、人物任务或费用时，先遵循[任务成本收益规则](./任务成本与收益规则_V1.md)，列出实际成本、收益、状态消费者与边界；然后按本页区间分别验证两模式。必须报告各站和操作档差异、诊断无误操作失败原因，保留统一时钟、一次性费用、资源上限、尿急禁冲刺和等待替代规则。学生优先维护真实操作成果与首关愉悦感；游客的寻路操作差异、公司追加要求、家长照顾负担继续通过实际事件发生，不以动态补时、隐藏必败或无效奖励凑成功率。
