# 预算、实际耗时与预测规则 V1

修订日期：2026-10-11。适用于四人物六站的路线、预算、HUD与结算；原设计稿保留。本规则承接任务成本收益、人物冲刺及孩子游戏时间结算规则。

## 共用成本

`src/timeModel.ts` 提供路线与移动公式，`src/gameClock.ts` 提供统一时间倍率与截止常量。

- 路线成本（游戏秒）= 地铁分钟×60 + 步行米数÷1.5÷当前普通移动倍率 + 换乘次数×单次换乘成本。
- 单次换乘：婴儿车90秒，行李45秒，其余20秒。创建预算、路线卡、实际行程和路线效率结算共用此计算。
- 普通移动倍率使用相应人物的实际函数；负重、疲劳、精力、抱娃、孩子体力及耗尽等因素按现有规则参与。未开放人物/旧流程没有人物状态时使用人物基础速度。
- 站内每段实际进度 = 现实秒×实际移动倍率÷该段基准秒数；预计剩余移动游戏秒 = 剩余段基准秒数×赶路倍率÷当前普通移动倍率。两者读取同一速度函数与现有旅程。选项修改路段长度或跳过路段后，预测读取修改后的结果。

## 初始预算是明确的难度政策

初始预算 = 向上取整至30秒的（本起点最快路线成本 + 当前普通速度的全站步行成本 + 操作/风险余量）+180秒停止检票偏移 − 极限模式削减。

现行基础操作余量：学生130秒、打工人150秒、游客185秒、家长180秒；普通／极限的整体削减均为0，所有车站的额外预算下限为0。固定站点修正与结果见[难度区间与首关体验 V3](./难度区间与首关体验_V3.md)，合理新手六站平均目标为学生85%–90%、打工人70%、游客60%、家长40%；中间三档优先±3、最多±5个百分点，未来家庭20%。参数统一来自 `src/difficulty.ts`，创建入口通过 `openingBudget` 调用同一预算公式；极限仍保留原有额外事件。取整和余量都是开局固定的难度参数，不伪装为路线耗时，不按玩家表现或胜负临时补时。

此前学生240／家长200／打工人游客480秒及极限120／105／360秒，是下方历史验收使用的旧政策；V1阶段的学生70／家长220／打工人480／游客100秒及上海打工人2130秒下限也已替代。V2的学生125秒由V3更新为130秒。历史准备、游客资源及孩子尿意变更见[难度校准规则 V1](./难度校准规则_V1.md)，人物新任务与操作口径仍见[人物规则 V2](./人物难点与事件规则_V2.md)。

修复后初始预算可能改变，因为预算以前用基础速度/固定20秒换乘，实际却用人物状态/行李成本。修改人物或路线参数时必须重新验算预算，不能再分别维护第二套路线公式。旧 `routeSeconds` 接口保留，底层共用同一价格分解，供没有动态人物状态的旧流程使用。

## 路线选定后锁价

`ROUTE` 将路线成本锁定到 `metroDuration`。此后实际行驶扣时与预测剩余路程都使用 `metroDuration × 剩余进度`。地铁途中恢复精力、睡觉、减负不会让已经选择的路线重新计价；这些资源仍影响后续站内移动。

预测到站后检票余量 = 当前实际剩余时间 − 检票截止偏移 − 尚未行驶的已锁定路线成本。未选路线时才按当前状态逐条估价；路线卡使用当前出发点的路线。估时包含步行/换乘，读题、开门等候、额外操作和意外另计；这些实际发生后只通过实际时间扣除体现一次。超出截止的路线卡显示预计超出时间，不能截成0秒掩盖风险。

所有人物主HUD统一显示实际检票倒计时，检票后显示距离发车时间；预计到站余量另放路线卡。避免不同人物使用不同含义的主倒计时。

## 剩余任务预测与结算

结算剩余任务估计共用路线锁价与站内移动公式。终点在检票前为 `gate-scan`，检票后为车门；地铁阶段失败仍保留未完成路线成本，不能因进入结果阶段归零。

站内预测假设：保持当前普通速度、不主动冲刺，每道题一般预留2秒读题；按住使用配置所需时间、连点按每次0.2秒估算；固定费用按当前可用选项中最低费用估算，当前事件扣除已用操作时间。尚未发生的资源变化、特殊阻挡、碰撞、未来选择及地铁开门等候不预言为实际耗时。预算操作余量是难度参数，与这套任务估计不要求数值相等。

预测只提供当前状态下的参考，结果中的未完成耗时继续标估计；实际消耗仍以倒计时变化及原日志为准。孩子尿意读取最终实际扣时，不读取预测；不会根据预测赠送恢复、消耗库存、产生冲刺收益或改变任务状态。

游客迷宫单独估计当前节点到出口的最短路线，包含每条20秒连廊、未知路口8秒看牌及每次2秒阅读；当前已确认路口可免去对应信息费用。不能用卡片最便宜的“看牌8秒”代替完整寻路成本，也不预言未来走错路。实际选择与预计剩余任务继续分开，详见[人物规则 V2](./人物难点与事件规则_V2.md)。

## 验证

新增测试覆盖四人物×六站×两档的预算组成，四人物实际地铁扣时与冻结预测，行李/婴儿车换乘成本，站内速度与部分进度，跳过/缩放路段，当前事件及地铁失败估计。路线UI渲染验证当前起点、完整成本及超过检票截止反馈。保留冲刺、孩子计时、大步/小步、六站及完整流程回归。

239项测试及生产构建通过。另以真实初始预算重跑4人物×6站×2难度×3策略144局，全部到达结算：89成功、55失败，无循环卡死；277个事件选项快照探测无非有限时间。策略包括实际读题及操作耗时、不同准备和路线、主动避障；结果是既定策略样本，不是玩家通关率，也不能把与旧审查的差异全部归因于本次预算公式。未进行浏览器手动试玩。
