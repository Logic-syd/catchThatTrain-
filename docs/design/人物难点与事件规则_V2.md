# 人物难点与事件规则 V2

修订日期：2026-10-11。按用户要求落实人物难点，当前目标与学生首关反馈配合[难度区间与首关体验 V3](./难度区间与首关体验_V3.md)；[难度阶梯校准 V2](./难度阶梯校准_V2.md)保留历史验证。原人物设计稿保留。后续改任务必须同时遵守任务成本收益、等待、资源边界与统一时间规则，不能只改卡片文字。

## 大学生：连续诱惑与剧情积分

六站均增加四道任务，放在不同旅程阶段。每道都可以立刻继续赶路，固定费用为0；读题和点击实际经过的时间仍正常扣除。

| 稳定事件 ID | 停下做什么 | 固定游戏秒 | 剧情收益 | 活动类型 |
| --- | --- | ---: | --- | --- |
| `student-cat` | 摸小猫 | 30 | 幸福感+20 | 停留 |
| `student-spectacle` | 围观 | 40 | 幸福感+20 | 停留 |
| `student-help-grandma` | 扶老奶奶去电梯再回来 | 35 | 道德+20 | 额外步行 |
| `student-tea-shop` | 买无须排队的茶颜悦色 | 25 | 幸福感+20 | 停留 |

选项 ID 为 `indulge/leave`。幸福感、道德从0开始，各封顶100，卡片显示当前可增加的实际值。它们由状态栏、资源日志、结算人物复盘消费；不参与精力、容量、专注、敏捷、恢复倍率、冲刺或路线价格，也不记成正的时间收益。站内这杯奶茶是剧情诱惑，不复用出门准备奶茶的能力增益。

停留仍遵循统一等待规则，可产生当时实际允许的自然恢复；这是等候时间的共用消费者，不是幸福感的效果。扶奶奶35秒明确为额外步行，不套静止恢复，也不附送体力。日志记录实际停留次数和固定费用总额；额外读题时间继续进统一时钟。

插入位置要保持已有操作连续：围观在扶梯乘坐之后，不能夹在选扶梯与进入扶梯操作之间。任何新事件也须检查下一段稳定 ID，避免改变旧选择的路段消费者。

## 打工人：新要求与未处理追问

出门准备 `reply` 仍消除原消息的提醒／原老板来电；它有实际收益。站内三条是新要求，不能被准备时的回复永久消除：`worker-company-ping`、`worker-company-revision`、`worker-company-call`。

| 选项 ID | 前两次消息 | 最后一次电话 | 后续效果 |
| --- | --- | --- | --- |
| `boundary` | 8 + 未处理数×12 秒 | 12 + 未处理数×15 秒 | 说明赶车、约好处理时间；清掉当前未处理数 |
| `work` | 40秒立即做完 | 无此选项 | 清掉当前未处理数；后续新要求仍会出现 |
| `ignore` | 0固定秒 | 0固定秒、专注最多−8 | 前两次未处理数+1；最后电话结束并清掉未处理数 |

`workPending` 初始0，消费者是下一道任务的标准费用和状态栏；不会只留一个无效旗标。费用按当前状态生成，点击时读取引擎标准选项，不能信任过期报价。正费用均是停留处理，按等待规则推进资源；专注减少按0边界显示，不虚报−8。

`workInterruptions` 记录实际处理的新要求次数，`workCalls` 只记实际处理的新电话；原 `bossCalls` 保留原提醒统计。结算合计电话次数时两者相加，不重复把同一次电话算成两通。准备取消的旧提醒仍可与新增任务区分。

## 游客：可循环的连廊迷宫

游客六站均有 `tourist-maze`。路口为地铁出口、商店岔路、出发层大厅、到达通道、行李寄存区、铁路安检入口；选择可能绕回以前的路口。左右布局按车站固定翻转，不在重绘或问路时重抽。最短路线需要实际走过三条连廊。

- `left/right`：固定步行20游戏秒、精力最多−2；等待份额0。只改变迷宫位置，不赠送常规站内位移、恢复或额外跑步累计。
- `sign`：停留8游戏秒，确认当前路口方向。
- `ask`：停留12游戏秒，确认当前路口方向。

未确认时，两条路均不直接标正确答案；问路／看牌后，卡片与对应按钮公开铁路出发方向，移除本路口的付费信息选项，防止为同一信息反复收费。确认不会跳过连廊；每到一个新路口仍需决定下一步。访问过的位置与已确认方向保留，折返回来不用再次购买信息；地图仅画实际走过的连接，未探索节点显示问号。终点持续可见，但未探索的正确路径不提前公开。

状态记录位置、已访问／已确认节点、路径、移动数、走错数、问路数、看牌数和 `revision`。每次有效操作更新revision，界面随它重置操作状态；引擎拒绝过期revision，防止重复点击旧卡片偷偷走到下一路口或重复收费。到安检入口才推进旅程段，结束后不再收迷宫费用。

预测使用当前节点到出口的最短连廊数，每条20秒、未知路口假设看牌8秒，每次操作预留2秒阅读。沿途已确认的路口免掉看牌与该次阅读，折返回来仍保留方向知识；不预测玩家未来错误，也不把看牌8秒误当完整迷宫费用。实际剩余时间始终按真实选择及读题推进。必要连廊／路标费用属于路线；结算额外损失只记录走错的20秒及问路相对看牌多出的4秒，不能把必要通行全标为失误。

## 带娃家长：怒气积累与停步发作

怒气从20开始，范围0–100；状态栏、卡片、资源日志与结算读取实际值。怒气峰值只增不减。它不直接增减速度，不以虚构随机必败判定结果。

| 事件／行为 | 固定游戏秒 | 怒气及其他效果 |
| --- | ---: | --- |
| `child-shoelace/help` 帮系鞋带 | 8，活动等待份额0 | 怒气+25 |
| `child-shoelace/drag` 催促继续走 | 0 | 怒气+35、孩子体力最多−6 |
| `child-distraction/comfort` 安抚蹲地上的孩子 | 等待10 | 怒气+35、耐心最多+10 |
| `child-distraction/carry` 抱起来 | 4，活动等待份额0 | 怒气+35、家长精力最多−4、抱娃并清掉距离差 |
| `child-distraction/shout` 大声催 | 0 | 怒气+55、孩子耐心最多−25 |
| 掉队／累／厕所／耐心耗尽／尿裤子处理 | 沿用原任务 | 每次怒气+18 |
| 上海购物、武汉买鸭及追加要求、广州抱娃 | 沿用原任务 | 每次怒气+12 |

怒气达到80，在既有4真实秒处理缓冲结束、当前没有其他事件时，逐帧推进会停止前进并解除冲刺，弹出 `parent-rage`：“今天就算不赶车，我也要揍你一顿！”这是角色发作时的念头；实际操作是处理怒气：

- `breathe`：等待12游戏秒，怒气最多−65、孩子耐心最多+8。
- `lecture`：等待45游戏秒，怒气最多−75、孩子耐心最多−18。

掉队及紧急厕所事件保留更高优先级。发作任务解决前不前进；解决后不跳过当前路段，玩家继续操作。`outbursts` 与 `rageDelaySeconds` 分别记录实际处理次数与12／45固定费用；没有实施殴打的操作或隐藏伤害值。

等待仍推进允许的家长／孩子被动资源，耐心已有定额时替代同段自然变化，怒气只由任务改变。孩子尿意继续读取动作实际扣掉的全部游戏时间，站内每分钟+4、地铁+2.5、其他阶段+0.45，上限100；12／45秒、读题和移动均只累计一次。尿意80起禁冲刺，95厕所、100意外等既有机制保留。固定等待不会制造追赶距离、同步冲刺收益或抱娃移动累计。

## 后续任务交付与验证

每项修改须列出稳定事件／选项 ID、固定步行／等待拆分、实际操作、资源边界、后续消费者及实际结算字段；纯剧情积分明确只进入剧情。改公司费用检查未处理状态；改迷宫检查环路、信息消费者、结束与旧revision拒绝；改怒气检查优先级、缓冲、停步与恢复后当前路段。

针对性测试位于 `characterChallenges.test.ts`、`characterChallengesUI.test.tsx`、`timeModel.test.ts`，覆盖六站人物任务、剧情积分无赶车属性增益、费用一次结算、旧回复与新任务、迷宫信息／折返／旧输入、预测与归因、怒气触发／不同选项／尿意时钟。完整回归、真实浏览器操作及独立种子结果以难度V2验收记录为准。家庭20%保留为未来目标，尚未开放或验证。

V2历史验收：37个测试文件、493项测试通过；生产构建通过。Chromium在390×844视口完成9项人物机制操作检查：摸猫、扶奶奶、公司未回复后续收费、迷宫实际环路、旧revision拒绝、已知信息不重复购买、跨卡片寻路完成、怒气与深呼吸一次结算、训话真实费用及耐心下降；原有按住／失焦／连点／闹钟等9项交互检查也通过，均无页面异常。这是针对性真实点击验证，不等同于全人物真人试玩。

V2历史14,400局完整输入模拟及144格聚合数据见[难度校准 V2](./难度阶梯校准_V2.md)和[验证 CSV](./难度阶梯验证_V2.csv)。该批学生约82%的结果对应旧预算，不能作为当前学生参数的证据。V3按用户更新的区间仅放宽学生固定开局余量，保留四次诱惑，站内实时显示实际 `runner.dodges` 与估算 `sprintSaved`，展示不增加资源或倒计时。新学生7,200局独立复测、495项完整回归和5项新增浏览器交互结果见[V3现行报告](./难度区间与首关体验_V3.md)；中间三档仍沿用未改参数的V2结果。不能把模拟达标写成已经证明真人胜率或愉悦感。

## 2026-10-13 修订：大学生虹桥的路边活动

大学生在虹桥的四个诱惑改为可直接路过的热点，主动停步才进入对应动作；活动完成或取消都保留当前未走完的道路。幸福感／道德、固定费用、实际等待与资源上限沿用本文规则，并用活动 revision 拒绝迟到回调。其他车站暂时沿用原事件形式。操作与迁移规则见[大学生虹桥操作模板 V1](./大学生虹桥操作模板_V1.md)。此前 v3 操作假设下的学生成功率是历史记录，新交互按 v4 独立复测。
