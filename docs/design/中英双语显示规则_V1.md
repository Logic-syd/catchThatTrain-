# 中英双语显示规则 V1

日期：2026-10-14。适用于四个人物、六站与普通／极限模式的现有游戏界面。

## 玩家入口

右上角始终显示 `中 / EN`，点击切换简体中文与英文。帮助、车票、地图、战绩和强制事件弹窗内提供同样的入口，保证鼠标、触屏和键盘都能在弹窗打开时切换。默认中文，刷新后读取本机此前保存的语言；浏览器不允许存储时仍能在当前会话切换。页面 `lang`、标题与简介同时更新。切换不会重开一局。

覆盖大厅、准备、路线与方向、地铁停站、站内操作、地图、资源和费用提示、结算、成就、战绩、分享文字及导出图片。中文城市与地铁站名在英文模式显示英文名或拼音，车次、票号、数值保持原值。

## 数据与翻译边界

- 游戏状态、事件／选项 ID、正式费用、资源效果、选择判断及日志保留原始语义数据。翻译作用于 JSX 显示文本与无障碍名称，不把译文写回 `Run` 或 `Choice`，也不翻译操作回调的提交值。
- `src/i18n.ts` 管理语言与显示转换。`src/locales/en.json` 保存完整文案和可组合片段；`en-patterns.json` 保存带 `{0}` 等参数的动态文案。复杂费用先按完整模板翻译，再突出成本，不能先拆中文字导致模板丢失。
- 数字、资源上限、固定成本、游戏秒／真实秒、概率和计时规则不得因语言不同而改变。等待收益与固定费用分别显示，沿用同一正式计算。
- 语言不进入事件组件的 `key`。已累计的按住进度、走位坐标、事件计时与当前任务必须保留；点击切换导致输入失焦时，沿用现有松手／失焦停止规则，重新输入即可继续。
- 语言偏好独立保存在 `train-rush:language:v1`，不修改成就或战绩结构。历史日期只在显示时转换格式，未知或无效日期保留原值。分享文字使用点击时的语言，链接中的称号保存原始中文，以便接收者切换；旧链接里的完整已知英文称号可还原显示。导出图片及文件名使用点击保存时的语言，异步生成期间切换不会混用语言。

## 后续修改

新增玩家可见文案时同步添加英文，包括动态资源详情、任务操作说明、地图图注、结果原因和无障碍标签。已有纯英文字符串及车次／票号直接显示。未知文本保留原值便于发现漏译，不能用泛化英文替换真实选项或隐藏费用。

参数模板必须有明确分界。不能用连续的任意文本参数猜测“花费／省下、约数、随机事件”等语义；这些分别设置模板，来源文案中包含逗号也不能错拆。组合片段无法完整翻译时保留原文，避免把未知任务翻成半中半英。回归测试除检查漏译，也检查语义、参数顺序和数字。

保持翻译语义与实际输入一致；“按住”“连点”“滑动”各自有对应英文。英文更长时优先合理换行、缩短可重复的提示和调整布局，关键入口与按钮仍需可操作。

验证范围包括：四人物×六站×两模式的准备／事件／结果文本、真实 UI 的切换与保存、事件中切换后的操作连续性，以及 320px／390px 布局。使用实际界面操作验证原始动作仍能正常提交；显示改动不沿用或重新包装难度模拟来声称真人成功率。
